# EzClip Frontend

> **Where Your Words Become Stories**  
> Effortlessly turn text, scripts, or audio into narrated, engaging videos with AI.

![EzClip Logo](public/vite.svg)

## What is EzClip?

**EzClip** is an AI-powered tool that transforms your text, story, or script into engaging narrated videos within minutes. Our mission is to make video creation effortless for everyone—teachers, marketers, storytellers, and creators of all kinds.

- **Turn your text into videos:** Paste your script or story and EzClip creates a professional-quality narrated video automatically.
- **Title-to-Video & Audio-to-Video:** Convert just a title, or upload an audio file, and let EzClip generate the visuals and narration.
- **Multiple formats:** Generate both portrait (9:16) and landscape (16:9) videos.
- **Effortless workflow:** No editing skills required. Focus on your content—EzClip does the rest.
- **Secure:** Private accounts and clear privacy policy.

## Features

- ✍️ **Text/Title/Audio to Video**: Multiple input options—just write, speak, or upload!
- 🗣️ **AI-Generated Narration**: High-quality, automatic voiceovers.
- 🎞️ **Instant Demo Videos**: See EzClip in action with example creations.
- 📋 **Account Management**: Easily sign up and manage your own generated videos.
- 🎨 **Modern UI**: Fast, responsive, and beautiful interface.

## Tech Stack

- **Frontend:** React 19, Vite, TailwindCSS
- **UI Libraries:** @radix-ui/react, lucide-react
- **Routing:** React Router DOM
- **API Handling:** Axios
- **Authentication:** Google One Tap (planned/partial)
- **Other tools:** ESLint, Font Awesome

---

## Getting Started

```bash
git clone https://github.com/legeRise/ezclip-frontend.git
cd ezclip-frontend
npm install
npm run dev
```

For a full build:
```bash
npm run build
npm run preview
```
